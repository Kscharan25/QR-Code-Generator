<h1 align="center">QR Code Generator</h1>

<p align="center">
  A simple and fast QR Code Generator built using <b>HTML, CSS, and JavaScript</b>.  
  Enter any text or URL, and the app instantly creates a QR code you can download as a PNG file.
</p>

<br>

<h2>Features</h2>
<ul>
  <li> Generate QR code from any text or URL</li>
  <li> Smooth loader animation while generating</li>
  <li> Download QR code as PNG</li>
  <li> Auto-clear QR when input field is empty</li>
  <li> Error shake effect for empty input</li>
  <li> Fully responsive & minimalist UI</li>
</ul>

<h2>How to Use</h2>
<ol>
  <li>Enter any text or URL in the input field.</li>
  <li>Click <b>Generate QR Code</b>.</li>
  <li>Wait for the QR code to appear.</li>
  <li>Click <b>Download PNG</b> to save it.</li>
</ol>
